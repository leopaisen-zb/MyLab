# Archive

This directory contains files moved out of the maintained Chapter 3 command path. Files are preserved for traceability, but they are not part of the primary Eqv2-Lite / Enhanced EquiformerV2 workflow.

## Subdirectories

| Path | Contents |
| --- | --- |
| `demos/` | Demo-style scripts. |
| `report_helpers/` | Report and figure helper scripts. |
| `public_packaging_helpers/` | One-off public-result packaging helpers. |
| `old_ablation_runners/` | Historical ablation runners and test scripts from `experiments/ablation/`. |
| `model_comparison_helpers/` | Historical model-comparison runner. |
| `legacy_oc20_src/` | Old OC20-style source entry points and utilities. |
| `later_chapter_application/` | Screening/cost/application code outside the Chapter 3 cleanup scope. |

## Still Not Archived

The following remain in place:

- core model code under `src/`,
- maintained scripts under `scripts/`,
- prepared datasets under `datasets/`,
- checkpoints under `checkpionts/`,
- result directories under `result/` and `experiments/`.

Archived files were moved without editing their contents.
