# 答辩意见汇总（2026-05-26）

## P0：核心问题（影响论文通过）

### 1. 第3章 Eqv2-Lite 剪枝参数多因素耦合实验缺失
- **问题**：Lmax=4、Rc=12.0Å 仅通过单因子实验验证，未考虑高熵合金表面无序性、多元素配位异质性影响
- **要求**：多因素耦合实验，优化剪枝策略以平衡轻量化、精度与场景适配性

### 2. 第4章 HEA-Gen 可合成性与动态奖励机制缺失
- **问题**：混合奖励函数权重分配缺乏动态调整机制，未考虑生成结构的可合成性约束
- **要求**："格式合规-物理保真-可合成性" 三位一体奖励机制

### 3. 第5章 MatGen-Eq 可扩展性不足
- **问题**：未解决多材料体系适配性与模型迭代兼容性
- **要求**：可扩展微服务架构，支持非铂族元素高熵合金、其他催化材料体系快速适配

### 4. 数据集覆盖局限 + DFT噪声未量化
- **问题**：数据集仅覆盖 IrPdPtRhRu 五元铂族体系，未系统分析 DFT 计算噪声对模型训练、结构生成及系统性能的量化影响
- **要求**：拓展数据集，构建噪声量化与抑制机制

### 5. 闭环未与 VASP 深度联动，效率提升未量化
- **问题**：闭环未实现与实验平台（如 VASP）深度联动，未量化闭环优化对材料研发效率的实际提升效果
- **要求**：AI与实验验证联动机制，量化闭环系统在实际科研场景中的应用价值与落地可行性

### 6. 第4章 HEA-Gen 实验细节缺失
- **问题**：实验数据量（训练/验证/测试样本数）、训练环境（Qwen2.5-7B + LoRA）、时间复杂度均未说明
- **要求**：补充完整实验配置信息

### 7. 第5章与第3/4章深度关联未说明
- **问题**：系统章节与前两章模型方法的逻辑关系不清晰
- **要求**：详细说明 MatGen-Eq 如何集成 Eqv2-Lite 与 HEA-Gen，逻辑关系是什么
