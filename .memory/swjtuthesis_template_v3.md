# swjtuThesisV3.0 模板格式规范

## 摘要环境

中文摘要使用 cabstract，英文摘要使用 eabstract。

## 关键词格式

- 中文：加粗"关键词：" + 中文逗号分隔，zihao{-4}（小四）
- 英文：加粗"Keywords:" + 英文逗号分隔，zihao{-4}（小四）
- 要求：3-8个关键词

## 章节格式

- 章标题：黑体，3号
- 一级节：黑体，4号
- 二级节：黑体，4号
- 三级节：黑体，小四

## 正文字体行距

- 正文：小四(12pt)，行距1.35倍
- 参考文献：五号(10.5pt)

## 页边距

- 上下边距：35mm
- 左右边距：30mm

## 页码规则

- 前置部分（摘要、目录）：罗马数字
- 正文部分：阿拉伯数字

## 编译要求

- 编译器：仅 XeLaTeX
- 选项：twoside,openany
